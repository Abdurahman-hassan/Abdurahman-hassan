## About me

I build backend services with Python, with a focus on clear API contracts, maintainable architecture, and reliable asynchronous processing. At **sonnen**, I work as a **Senior Backend Software Engineer** in the energy technology sector.

My experience spans **Django, Django REST Framework, FastAPI, and Flask**, alongside **Kafka** for event-driven systems, **PostgreSQL** for relational data, and **Celery and Redis** for background processing. I also work with **AWS and Terraform** for cloud infrastructure.
